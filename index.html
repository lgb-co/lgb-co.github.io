The Gallery: Selected Works and Case Studies

In the 3D gallery room, you can walk through an exhibition of my most significant commercial and personal projects. Here is a detailed breakdown of the work created by LGB-CO.

AESTHETIC-DIRECTOR — Open-Source AI Skill

AESTHETIC-DIRECTOR is an open-source "aesthetic director" skill for AI coding agents such as Codex and Claude Code. It distills four methodologies into one workflow: anti-slop frontend rules, a motion decision framework with exact easing and duration values, six photo-to-poster art styles, and a copy-to-PV-animation prompt pipeline. The project ships as a structured SKILL.md with reference files, is written in Chinese for practical day-to-day prompting, and is released under the MIT license on GitHub. It is synthesized from and credited to taste-skill, impeccable, and emilkowalski/skills.

AI ANIME PV — Manhua to Video Pipeline

An ongoing experiment that turns the manhua Riyue Tongcuo (日月同错) into a 60-second vertical AI animation trailer. The pipeline covers storyboard breakdown, per-shot image-to-video prompts with first-frame control from original manga panels, AI voice acting, sound design, and unified color grading. The full production kit — style cards, shot tables, and ready-to-feed prompts — is documented and shared as a reusable workflow.

THIS 3D WORLD — Hand-drawn Portfolio

The very website you are walking through. It is built on ITom's open-source 3D portfolio (React Three Fiber + GSAP + WebGL), customized with my own content: hand-drawn style textures generated procedurally, localized project data, and deployment on GitHub Pages as a personal site. The project demonstrates how far an open-source base plus AI-assisted editing can go in half a day.
